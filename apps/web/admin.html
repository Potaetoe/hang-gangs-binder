Before you close this

      

        This page is the only place the submissions exist in the clear.
        Closing the tab discards everything decrypted here, and the admin
        session is tab-scoped too — but the key is not. Once you import
        it, it stays on this device so later exports need no file, and
        Clear is what removes it. Press Clear before you
        leave this browser on a machine someone else can reach. Keep your
        key file as well: the browser may drop stored data, and the file
        is what puts the key back.
